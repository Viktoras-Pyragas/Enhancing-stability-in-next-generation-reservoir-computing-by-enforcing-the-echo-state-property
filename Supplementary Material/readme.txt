In this directory we provide the matlab files for the Supplementary Material of
our paper;

In the directories /KS_fugure/, /MG_figure/ and /Mont_figure/ we plot
all the three graphs contained in the Supplementary Material;

The directories /KS_matlab/, /MG_matlab/ and /Mont_matlab/ contain matlab
programs which compute the data files necessary to plot the graphs;

%-----------------------------------------------------------------------------------

Here we use the following abbreviartions:

KS -> Kuramoto Sivashinsky (see the model description in DOI: 10.1103/PhysRevE.108.054220)

MG -> Mackey-Glass (see the model description in DOI:10.4249/scholarpedia.6908)

Mont -> Montbrio (see the model description in DOI: 10.1103/PhysRevE.111.014422)
